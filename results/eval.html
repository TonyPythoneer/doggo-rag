DOGGO RAG evaluation

Does a second look with retrieved animal facts help each model spot domestic dogs?

How to read this

  1. First Pass: the model looks at the photo alone and answers “Domestic dog”, “Not a domestic dog” or “Uncertain”.
  2. Second Pass: the same model looks at the same photo again, this time with its first answer and animal facts found by RAG retrieval.
  3. Both passes are scored on the same photos. A run that failed is listed separately and is never counted as a wrong answer. “Uncertain” counts as wrong. Dingoes count as not a dog.
  4. A green ▲ means the second look got more answers right; a red ▼ means fewer. “pp” = percentage points.
